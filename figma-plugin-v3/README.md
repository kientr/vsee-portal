# VSee Patient Portal — V3 Flow → Figma (native layers)

A Figma **plugin** that rebuilds the current **v3 prototype**
(https://kientr.github.io/vsee-portal/v3/) as real, editable Figma frames,
text, and shapes — using the app's actual design tokens.

> **Why a plugin?** Figma has no external/REST API for *creating* design
> content. Frames and layers can only be generated by code running inside
> Figma, so this is delivered as a one-click plugin you run in your file.

## Screens generated (20)

Login · Dashboard · Visits & e-consults · Visit detail · **E-consult ticket** ·
See a provider (1 Provider · 2 Visit type · 3 Pick a time · 4 Review) ·
Confirmation · Requests · Request detail · New request · Messages ·
Forms & Documents · Intake form · Medical Records · Profile ·
Settings (Features) · In-call.

Matches the corrected v3 IA — sidebar is **Care** (Visits, Requests, Messages) /
**Health** (Forms & Documents, Medical Records) / **Account**; e-consult is a
visit type; "See a provider" lives on the Visits header. Each screen is a
`1440`-wide frame named `V3 · <Screen>`, laid out in a 4-column grid.

## How to run

1. Open your Figma file (the plugin anchors near node `1:2` if present,
   otherwise the current page).
2. **Plugins → Development → Import plugin from manifest…**
3. Select `figma-plugin-v3/manifest.json`.
4. **Plugins → Development → "VSee Patient Portal — V3 Flow"**.
5. It builds all 20 frames, selects them, and zooms to fit.

Fonts: **Inter** (bundled with Figma); buttons use **Figtree** if installed,
else fall back to Inter Bold.

Verified: parses clean and runs end-to-end against a mock Plugin API
(20 frames; valid enums/resizes; no throws).
