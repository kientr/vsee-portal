# VSee Patient Portal — V2 → Figma (native layers)

A Figma **plugin** that rebuilds the live **V2 flow**
(https://kientr.github.io/vsee-portal/) as real, editable Figma frames,
text, and shapes — using the app's actual design tokens (colors, type,
radii, spacing from `src/styles.css`).

> **Why a plugin?** Figma has no external/REST API for *creating* design
> content — frames and layers can only be generated by code running inside
> Figma. So this is delivered as a one-click plugin you run in your file.

## Pages generated (14)

Login · Dashboard · Visits & e-consults · Visit detail · See a provider ·
Messages · Forms & Documents · Intake form · Medical Records · Profile ·
Settings · In-call (telemedicine) · Schedule a visit · Send an e-consult

Each is a `1440`-wide frame named `V2 · <Screen>`, laid out in a 3-column
grid. The shared **sidebar** and **topbar** are rebuilt as auto-layout so
they stay editable. Everything is native (no flattened images).

## How to run

1. Open your Figma file (e.g. the one at your shared link). The plugin
   anchors near node `1:2` if it exists, otherwise it draws on the current
   page.
2. **Plugins → Development → Import plugin from manifest…**
3. Select `figma-plugin/manifest.json` from this repo.
4. **Plugins → Development → "VSee Patient Portal — V2 Pages"**.
5. It builds all 14 frames, selects them, and zooms to fit. Done.

Fonts: uses **Inter** (bundled with Figma). Buttons use **Figtree** if
installed, else fall back to Inter Bold — no missing-font prompts.

## Editing

- Tokens live at the top of `code.js` (`C`, `R`, `SIDEBAR_W`, …) — change a
  value and re-run to regenerate.
- Each screen is its own `build*()` function composed from the component
  builders (`card`, `button`, `badge`, `avatar`, `navItem`, `sidebar`,
  `topbar`, `shell`, …).
